# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities through a public issue.

If you discover a vulnerability, contact the maintainer privately and include enough information to reproduce and assess the issue.

Never include Discord tokens, API keys, credentials, private configuration, or personal data in a report.

## Secrets

Aven Moderation does not require secrets to be committed to the repository. Runtime credentials must be supplied through environment variables.

If a credential is accidentally committed, treat it as compromised and rotate it immediately.
